Choose the right remediation tier

A plain validator tells you what is wrong. The remediation endpoints group findings by priority and issue code, explain business impact, and return concrete corrective actions. Use the $1 route for up to 100 products, the $5 batch route for 101–500 products, and the $20 full-catalog route for up to 2,000 products when you want one payment and one result.

Example batch request

curl -X POST https://pal-nano-catalog-audit.onrender.com/v1/usdc/catalog-remediation-batch \
  -H "content-type: application/json" \
  -d '{
    "records": [{
      "id": "sku-100",
      "title": "Example Product",
      "link": "https://example.com/products/sku-100",
      "image_link": "https://example.com/images/sku-100.jpg",
      "gtin": "4006381333931",
      "brand": "Example",
      "mpn": "SKU-100",
      "price": "19.99 USD",
      "availability": "in_stock",
      "identifier_exists": true
    }]
  }'

The first unpaid request returns HTTP 402 with the exact Base-USDC payment requirement. After settlement, retry the same request with the x402 payment signature to receive the JSON result.

Marketplace integration

For marketplaces that handle billing themselves, PAL exposes a separate machine-readable OpenAPI definition with catalog audit, catalog remediation, GTIN validation, feed diff and x402 declaration validation operations.

Marketplace OpenAPI: pal-nano-catalog-audit.onrender.com/marketplace-openapi.json

Privacy and scope

No Shopify login, Merchant Center token, customer data, order data or private key is required. PAL operates on the catalog/feed records you submit. Results are deterministic technical guidance and do not guarantee Merchant Center approval or regulatory compliance.

Current distribution

The production API is published in the Official MCP Registry as io.github.enricoaboujaoude-droid/pal-commerce-catalog-intelligence and exposes a remote Streamable HTTP MCP server at /mcp.
