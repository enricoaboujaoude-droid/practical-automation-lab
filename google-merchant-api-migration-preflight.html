Recommended migration order

    What the scanner checks

    • Content API v2.1 endpoints, client-library names and common Products / Accounts / Datafeeds / Reports surfaces.
    • customBatch usage, which has no direct Merchant API equivalent.
    • Legacy product identifier handling that should move toward Merchant API resource name / parent patterns.
    • Legacy Price objects using value + currency instead of amountMicros + currencyCode.
    • Merchant API v1beta references that should already be migrated to v1 or an appropriate supported v1alpha surface.
    • Merchant API usage without an obvious developerRegistration:registerGcp / registerGcp step in the scanned material.

    Static analysis can produce false positives and cannot prove a migration is complete. Always test against Google's current Merchant API documentation and a development environment before production rollout.
