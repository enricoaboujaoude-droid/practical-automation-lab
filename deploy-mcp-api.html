2. Make the service machine-readable

Expose an OpenAPI document or MCP server description. If the service is paid, make the payment contract machine-readable too. For x402, an unpaid request should return a standards-compliant 402 Payment Required response.

  • Keep /health or an equivalent health endpoint free.
  • Publish OpenAPI or MCP tool schemas.
  • Use deterministic request and response shapes.
  • Keep cold-start latency low enough for agent buyers.
