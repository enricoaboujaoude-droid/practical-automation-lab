HubSpot API Migration Preflight

A free, browser-local checklist for teams reviewing custom HubSpot integrations during the 2026 developer-platform transition. No HubSpot login, token or CRM data is required.

Check your integration

What this checks

It highlights migration questions worth validating before changing production integrations: credential model, webhook architecture, API-version exposure, and whether CRM write operations can conflict with admin-configured validation.

This is a planning aid, not a guarantee that an integration will pass every HubSpot requirement. Always verify the current HubSpot developer documentation before production changes.
